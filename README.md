# 重力2048

重力2048是一款基于经典 2048 玩法的网页小游戏。方块会受重力影响下落，相同数字的方块相遇会合并，还可以通过改变重力方向来移动方块。

在线体验：<https://tuxlin123233.github.io/>

## 玩法介绍

- 方块掉落：点击棋盘顶部的任意空白格，会生成一个方块（2、4 或炸弹）并受重力下落。
- 方符合并：相同数字的方块在重力下落时相遇会自动合成一个更大的方块，分数随之增加。
- 炸弹方块：带有 `B` 标识的炸弹（如 `B2`、`B4`、`B8`），数字越大威力越强。被合并到棋盘上的炸弹会爆炸，摧毁 3×3 范围内的方块（大于威力的方块会被相除减弱）。
- 改变重力：点击下方的左右箭头可以让整个棋盘向对应方向滑动，方块会相互碰撞并合并。

## 界面说明

| 区域 | 说明 |
| --- | --- |
| 分数 | 当前累计得分 |
| 次数 | 已执行的生成/移动次数 |
| 未来方块 | 下一个将要生成的方块预览 |
| 棋盘 | 4×4 游戏区域，点击顶部空格生成方块 |
| 箭头按钮 | 左右改变重力方向 |

## 技术栈

- 原生 HTML / CSS / JavaScript（无任何框架依赖）
- 思源黑体（Source Han Sans SC）字体
- 内置音效：生成、合成、爆炸、重力音效

## 项目结构

```
├── arrow-left.svg          # 左箭头图标
├── arrow-right.svg         # 右箭头图标

├── force.mp3               # 重力音效
├── generate.mp3            # 生成音效
├── icon.png                # 网站图标
├── index.html              # 页面结构
├── main.js                 # 游戏逻辑
├── style.css               # 样式
├── synthesize.mp3          # 合成音效
└── SourceHanSansSC-Regular-2.otf  # 思源黑体字体文件
```

## 本地运行

直接打开 `index.html` 即可游玩，或使用任意静态服务器：

```bash
# 方式一：直接浏览器打开
open index.html

# 方式二：使用 Python 启动本地服务器
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```
